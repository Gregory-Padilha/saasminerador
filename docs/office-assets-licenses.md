## 📌 Especificação dos Assets

### 1. Ambientes e Pisos (`public/office/art/tiles/`)
- `wood_floor_tile.svg`: Piso de madeira nobre para diretoria e biblioteca.
- `carpet_tile.svg`: Carpete executivo grafite para os departamentos (Mercado, Oferta, GTM).
- `tile_floor.svg`: Cerâmica clara para copa e café.
- `lounge_rug.svg`: Tapete roxo com bordas suaves para o lounge.

### 2. Móveis e Equipamentos (`public/office/art/furniture/`)
- `desk_workstation.svg`: Estação de trabalho com pernas metálicas.
- `desk_director.svg`: Mesa de nogueira para a diretoria.
- `chair_ergonomic.svg`: Cadeira de escritório ergonômica ajustável.
- `chair_meeting.svg`: Cadeira executiva de reunião.
- `monitor_dual.svg`: Configuração de monitores duplos com brilho azul/ciano.
- `monitor_vertical.svg`: Monitor vertical para estrategista de Copy/LP.
- `monitor_alert.svg`: Monitor com indicador de alerta para Auditor.
- `bookshelf_large.svg`: Estante com livros e tomos coloridos.
- `sofa_lounge.svg`: Sofá duplo acolchoado em veludo.
- `armchair_lounge.svg`: Poltrona acolchoada.
- `coffee_station.svg`: Balcão com máquina expresso e xícaras.
- `pool_table.svg`: Mesa de sinuca profissional com feltro verde esmeralda, mogno, caçapas e bolas.
- `meeting_table_oval.svg`: Mesa de reunião oval para o Review Board.
- `operations_terminal.svg`: Tela de parede de operações do Case File.
- `plant_potted.svg`: Vaso com planta decorativa.

### 3. Avatares dos 13 Agentes (`public/office/art/agents/`)
- Ilustrações 2.5D com ~48px de altura contendo cabeça, cabelo, tronco, braços/pernas simplificados e sombras projetadas.
