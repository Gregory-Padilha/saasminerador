# DOCTRINE 04: OFFER MODELING METHODOLOGY (MODELAR NÃO É CLONAR)

## 1. REGRA ABSOLUTA: MODELAR != COPIAR
- **Clonar / Copiar**: Baixar criativos alheios, copiar copy verbatim, plagiá-los na íntegra ou trocar apenas o nome da marca. Prática antiética, ilegal e ineficiente que destrói a percepção de novidade no tráfego.
- **Modelar**: Compreender a LÓGICA COMERCIAL e o MECANISMO ESTRUTURAL de uma oferta validada e criar **UMA NOVA EXPRESSÃO TOTALMENTE INÉDITA**.

---

## 2. O MÉTODO DE MODELAGEM EM 5 ETAPAS

```text
DECONSTRUCT ➔ PRESERVE ➔ TRANSFORM ➔ REBUILD ➔ TEST
```

1. **DECONSTRUCT (Desmontar)**: Extrair o DNA da oferta original (Avatar, Dor, Promessa, Mecanismo, Pricing, Bumps, Criativos).
2. **PRESERVE (Preservar)**: Manter apenas a **Estrutura Transferível** (mecanismo comercial, faixa de preço, formato do funil, lógica dos order bumps).
3. **TRANSFORM (Transformar)**: Alterar obrigatoriamente 2 ou mais elementos chave:
   - *Novo Avatar / Sub-público* (ex: Oferta para Designers ➔ Modelagem para Fotógrafos).
   - *Novo Ângulo / Gancho* (ex: Ângulo de economia de tempo ➔ Ângulo de facilidade/zero esforço).
   - *Novo Mecanismo* (ex: Guia passo a passo ➔ Matriz de Prompts Editáveis).
   - *Novo Formato de Produto* (ex: Ebook longo ➔ Fichário digital / Cards rápidos).
4. **REBUILD (Reconstruir)**: Montar uma nova marca, nova copy, nova headline, novos criativos originais e novas landing pages.
5. **TEST (Testar)**: Planejar um teste de tráfego direto enxuto para validação inicial de CPA.
